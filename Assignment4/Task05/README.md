# Task 5 – Four Event-Handling Styles

**Objective:** Implement the same currency converter using four Java listener approaches.

1. The frame implements ActionListener.
2. A named inner listener class.
3. An anonymous inner listener class.
4. A lambda expression.

The example uses fixed demonstration rates (USD 0.012 and EUR 0.011 per INR), not live exchange rates. Both the Convert button and Enter key trigger conversion.

**Run**
```bash
javac task5.java
java task5 1
java task5 2
java task5 3
java task5 4
```
Test valid, negative, and non-numeric values. Add screenshots of your results.
