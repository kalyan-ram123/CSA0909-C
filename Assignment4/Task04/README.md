# Task 4 – Event-Handling Drawing Pad

**Objective:** Handle mouse clicks and redraw stored points.

The MouseAdapter receives click events. Each point is stored in a collection, the count label is updated, and repaint() redraws all points so they remain visible after the window is refreshed.

**Run**
```bash
javac task4.java
java task4
```
Click several places in the window, then minimise and restore it. Record the observed behaviour.
