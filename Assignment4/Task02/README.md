# Task 2 – Hospital Outpatient Appointment Desk

**Objective:** Use Swing components and event listeners to build an appointment form.

Changing the department refreshes the doctor list. The Book button checks the patient ID and displays a confirmation using the selected doctor and time slot. This is a user-interface demonstration, not a live booking service.

**Run**
```bash
javac task2.java
java task2
```
Capture your own screenshots showing department changes, validation, and confirmation.
