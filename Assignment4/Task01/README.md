# Task 1 – Student Fee Payment GUI

**Objective:** Design an AWT form and handle Pay, Clear, and Receipt actions.

The form validates the register number and amount, displays feedback, and separates validation/payment demonstration logic from button listeners. It does not process a real payment.

**Run**
```bash
javac task1.java
java task1
```
Test blank IDs, non-numeric amounts, zero, negative and valid amounts. Add your own execution screenshot.
