# Task 3 – Campus Library Search Layout

**Objective:** Arrange search controls, results, and navigation using Swing layout managers.

BorderLayout gives the central results list the available resize space. A scroll pane allows longer result lists to be viewed. The displayed books are sample data only.

**Run**
```bash
javac task3.java
java task3
```
Resize the window and record how the central results area changes. Add screenshots at different sizes.
