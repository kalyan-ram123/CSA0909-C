# Assignment 4 – Event-Driven GUI Design (CO4)

This folder contains six independently written Java examples based on the topics in the public reference assignment.

## Tasks
1. Student fee payment form and GUI design
2. Hospital appointment desk
3. Campus library search layout
4. Mouse-event drawing pad
5. Currency converter with four listener styles
6. Campus event registration using JDBC

## Requirements
- JDK 8 or later
- Task 6 additionally requires MySQL Server and MySQL Connector/J

Compile and run each task from its own folder. For example:
```bash
cd Assignment4/Task04
javac task4.java
java task4
```

Task 6 database configuration and setup are documented in its README. The GUI examples use sample data; they are demonstrations, not production payment, hospital, or library systems.
