# CSA0909 — Programming in Java
## Assignment 2: Strings and Java Collections

This folder contains independently written Java solutions for all seven Assignment 2 topics. The work is organized task-wise and includes a short explanation and compile/run instructions.

| Task | Topic |
|---|---|
| 1 | String, StringBuilder and StringBuffer |
| 2 | ArrayList, LinkedList and ArrayDeque |
| 3 | HashSet, equals() and hashCode() |
| 4 | HashMap, TreeMap and LinkedHashMap |
| 5 | Generics and Comparator-based leaderboard |
| 6 | Queue and PriorityQueue |
| 7 | Diagnose, redesign and validate string building |

### Requirements
- JDK 8 or later
- Open a terminal inside the required task folder.

### Run
For example:
```bash
cd Task01
javac task1.java
java Task1
```
Use the matching source filename and class name for each task.
