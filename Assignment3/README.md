# Assignment 3 – Java Programming (7 Tasks)

This folder contains independently written Java examples covering exception handling, file handling, and multithreading.

## Tasks
1. Exception handling and input validation
2. Custom exceptions and exception chaining
3. File handling with try-with-resources
4. Thread creation, sleep, and join
5. Synchronization with shared seat booking
6. Producer-consumer using wait() and notifyAll()
7. ExecutorService, Callable, and Future

## Requirements
- JDK 17 or later

## Compile and run
From the repository root, run the command for the task you want:

```bash
javac Assignment3/Task01/Task1.java
java -cp Assignment3/Task01 Task1

javac Assignment3/Task02/Task2.java
java -cp Assignment3/Task02 Task2

javac Assignment3/Task03/Task3.java
java -cp Assignment3/Task03 Task3

javac Assignment3/Task04/Task4.java
java -cp Assignment3/Task04 Task4

javac Assignment3/Task05/Task5.java
java -cp Assignment3/Task05 Task5

javac Assignment3/Task06/Task6.java
java -cp Assignment3/Task06 Task6

javac Assignment3/Task07/Task7.java
java -cp Assignment3/Task07 Task7
```

Each task has its own README with its objective and run instructions. Outputs involving threads may appear in a different order on each run.
