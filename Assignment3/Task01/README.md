# Task 1 – Exception Handling

**Objective:** Practice try, catch, multi-catch, finally, and input validation.

The program simulates a withdrawal from a sample account balance. It handles invalid amounts, insufficient balance, and non-numeric input.

**Run from repository root:**
```bash
javac Assignment3/Task01/Task1.java
java -cp Assignment3/Task01 Task1
```
Try a valid amount, a negative amount, an amount above the balance, and text input. Record the output produced on your own system.
