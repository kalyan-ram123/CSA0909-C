# Task 4 – Thread Life Cycle

**Objective:** Demonstrate Runnable, Thread, start(), sleep(), and join().

Four worker threads run concurrently. The main thread uses join() to wait until every worker has completed. The order of worker messages can vary.

**Run from repository root:**
```bash
javac Assignment3/Task04/Task4.java
java -cp Assignment3/Task04 Task4
```
