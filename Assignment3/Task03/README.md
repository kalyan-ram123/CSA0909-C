# Task 3 – File Handling with Try-with-Resources

**Objective:** Read and write text files and automatically close resources.

The program reads comma-separated sales records from `sales.txt`, calculates the total, and writes a report to `sales-report.txt`. If the input file does not exist, sample records are created.

**Run from repository root:**
```bash
javac Assignment3/Task03/Task3.java
java -cp Assignment3/Task03 Task3
```
The two text files are created in the directory from which the Java command is run.
